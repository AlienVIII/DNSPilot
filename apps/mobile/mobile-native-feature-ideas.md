# Mobile Native Feature Ideas

- User-started foreground benchmark with saved recommendations.
- D14 mobile feasibility: supported iOS continued-processing and bounded Android native
  foreground execution may continue one run after app switch, with contextual local
  notification opt-in. Do not promise force-quit survival or auto-retry.
- Shareable diagnostics report.
- Settings guidance per OS.
- Optional iOS DNS settings profile flow after entitlement review.
- Android Private DNS guide with copyable hostname where applicable.
- Lightweight widgets only if they do not imply scheduled or silent background testing.
